# 佩欣每日工作台原型

這是一個離線靜態 Web prototype，用來驗證「課務 + 核銷」雙工作台是否能減少佩欣每天人工比對、缺漏檢查、訊息整理的時間。

## 使用方式

1. 直接用瀏覽器開啟 `prototype/index.html`。
2. 左側已放入兩份 Google Sheet 來源：
   - 馴錢師財商研究中心 - 課程邀約申請表單 (回覆)
   - 馴錢師報帳表單 (回應)
3. 先看內建 demo data 的總覽、課務、核銷與草稿。
4. 從左側來源卡開啟 Google Sheet，或點 CSV 下載後匯入：
   - 課程邀約申請表單 CSV
   - 馴錢師報帳表單 CSV
5. 檢查工作台產出的缺漏欄位、核銷金額差異、交通資訊待補、訊息草稿。
6. 使用「匯出」下載 Markdown 日報。

## Prototype 邊界

- 只在瀏覽器本機處理 CSV，不會上傳資料。
- 不會寫回 Google Sheets、Info、Calendar，也不會發送 Line 或 Email。
- 已綁定的 Google Sheet 連結只作為來源入口；私人表單若未登入或沒有權限，CSV 下載仍會被 Google 擋下。
- 內建 demo data 是去識別化假資料，不含原始表單個資。
- 實際導入前，仍需請佩欣確認欄位規則、交通費計算規則、專案費率與訊息模板。

## 對應需求

- 課務：新申請、缺漏欄位、待派講師、待確認 Calendar/建檔、Line 草稿。
- 核銷：依專案與請款人整理、明細加總與總計比對、單據數量/日期/交通起訖缺漏、逐人通知草稿。
- 治理：維持 report-first、draft-first，不做外部發送或發薪相關全自動寫入。
